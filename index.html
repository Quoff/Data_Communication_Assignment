What I Studied in Data Communication

Data Communication Basics

Data communication is the exchange of information between devices through a transmission medium such as cables, wireless signals, or satellite links.

Network Devices

I studied routers, switches, modems, access points, and servers. These devices help data move across local and wide area networks.

Transmission Media

Transmission media include twisted pair cable, coaxial cable, fibre optic cable, radio waves, microwave, and satellite communication.

Protocols

Protocols are rules that guide communication between devices. Examples include TCP/IP, HTTP, FTP, SMTP, DNS, and DHCP.

Network Security

Data must be protected using authentication, encryption, firewalls, passwords, access control, and secure network design.

Satellite Communication

Satellite communication supports broadcasting, navigation, internet access, global connectivity, and long-distance data transmission.

Diagram of a Telegraph

The telegraph was one of the earliest long-distance communication systems. It used electrical signals to send coded messages across wires.
